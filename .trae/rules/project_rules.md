# Project Rules

本文档定义了 iDiary.ai Hebe 项目的开发规范和配置要求。

## 目录结构

### 文档目录
- **路径**: `docs/`
- **用途**: 存放项目文档，包括架构设计、开发指南、API 文档等
- **格式**: Markdown
- **要求**: 必须包含 README、API 文档和变更日志

### 测试目录
- **路径**: `tests/`
- **用途**: 存放所有测试代码，包括单元测试、集成测试等
- **结构**: 按模块和测试类型组织

## 技术栈规范

### Go 语言
- **版本**: 1.24
- **特性要求**:
  - 使用 Go Modules
  - 使用 Go Work
  - 使用泛型 (Generics)
  - 使用 embed 包

### Gin 框架
- **版本**: 1.10.0
- **使用规范**:
  - 使用 Context
  - 使用中间件 (Middleware)
  - 使用路由组 (Group)
  - 使用数据绑定 (Binding)

### JavaScript
- **版本**: ES2023
- **浏览器支持**:
  - Chrome 110+
  - Edge 110+
  - Firefox 128 ESR+
- **编码规范**:
  - 使用严格模式
  - 使用模块化
  - 使用 async/await
  - 使用箭头函数
  - 使用 const/let
  - 使用模板字符串
  - 使用解构赋值
  - 使用展开运算符
  - 使用可选链
  - 使用空值合并运算符

### jQuery
- **版本**: 4.x
- **使用规范**:
  - 使用现代 API
  - 避免已弃用的方法

### Tailwind CSS
- **版本**: 4.x
- **使用规范**:
  - 使用现代类名

## 国际化 (i18n)

### Kiko 插件
- **类型**: 插件
- **路径**: `kiko/src/i18n`
- **策略**:
  - 默认语言: en
  - 回退语言: zh-CN
  - 命名空间: kiko

### Website 应用
- **类型**: 应用程序
- **路径**: `website/static/src/js/i18n`
- **策略**:
  - 默认语言: en
  - 回退语言: zh-CN
  - 命名空间: website.js
  - 作用域: website/static/src/js

## 代码质量要求

### JavaScript
- **代码检查**:
  - 启用 ESLint
  - 启用 Prettier
- **复杂度控制**:
  - 最大函数长度: 50 行
  - 最大参数数量: 4 个

### Go 语言
- **代码检查**:
  - 启用 golangci-lint
- **复杂度控制**:
  - 最大函数长度: 60 行
  - 最大参数数量: 5 个

## 扩展和插件

- **状态**: 启用
- **自定义规则**: 可根据项目需要添加

## 文档要求

- **格式**: Markdown
- **必需文档**:
  - README 文件
  - API 文档
  - 变更日志

*本规则文档基于项目配置自动生成，如需修改请更新相应的配置文件。*
