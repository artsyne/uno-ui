This page demonstrates the Directive-Driven validation plugin (v0.8.0+).

  • Auto Error Generation: Error messages are automatically injected after the input. No manual error `div`s needed!
  • Array Configuration: Rules are defined in `x-uno-valid` (e.g., `['required', 'email']`).
  • HTMX Integration: Automatically intercepts `hx-post` if validation fails.
  • Async & Debounce: Native support for async validators with debounce.
