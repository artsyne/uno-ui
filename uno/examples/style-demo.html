UNO Style Demo

Theming System

This page demonstrates the Brutalist Theme applied via UnoConfig.ui. We've overridden the default rounded corners, shadows, and colors globally. 

window.UnoConfig = {
    ui: {
        base: {
            rounded: 'rounded-none',
            shadow: 'shadow-[4px_4px_0px_0px_rgba(0,0,0,1)] border-2 border-black',
            primary: 'bg-yellow-400 text-black ...'
        },
        tooltip: {
             // Essential for custom styles: must include 'fixed'
             content: 'fixed z-[20000] ... bg-black text-yellow-400 ...'
        }
        // ... more overrides
    }
}
